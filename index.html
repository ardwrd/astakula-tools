What is Astakula Tools?

Astakula Tools is a collection of web-based utilities developed by Ariyo Ardiwardana under Astakula.

Most tool processing runs directly in the browser. The DNS Inspector is the current exception: it sends the requested domain and record type to Cloudflare's public DNS-over-HTTPS resolver. Some tools, such as Work Schedule Generator, also keep editable project data in browser storage on the user's device. Certificate Generator keeps uploaded template and participant data in the browser, while selected web fonts are requested from Google Fonts.
