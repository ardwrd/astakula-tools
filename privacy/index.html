At a glance

The main privacy behavior of the current public implementation can be summarized in three points.

Most tools Process input inside the browser.
External lookups DNS Inspector uses Cloudflare DNS-over-HTTPS; GitHub Inspector calls GitHub REST API; Certificate Generator can load fonts from Google Fonts.
Browser storage Stores theme preference in localStorage and Work Schedule projects in IndexedDB on the device.
01

Scope

This Privacy Policy applies to the public website at tools.astakula.com. Astakula Tools is a collection of browser-based utilities developed by Ariyo Ardiwardana under Astakula.

This page describes the behavior verified from the current project source. If the implementation or hosting stack changes, the policy should be reviewed again.

02

How tool inputs are processed

The current repository does not contain an Astakula application backend, account system, or server-side database for storing tool inputs. Some tools can intentionally persist editable data in browser storage on the user's device.

03

Local browser storage

Astakula Tools stores the selected light or dark theme preference in the browser's localStorage. That preference remains on the device until it is changed, cleared by the browser, or otherwise removed by the user.

The Work Schedule Generator uses IndexedDB to keep editable schedule projects on the user's current browser profile. A saved project can include the selected month, team or department name, employee names and roles, employee day-off requests and optional request notes, shift definitions, scheduling rules, generated or manually adjusted assignments, validation results, and update timestamps.

Schedule projects are not synchronized between devices or browser profiles by the current implementation. They can become unavailable if the browser's site data is cleared, the user changes browser profile or device, private browsing discards storage, or the browser removes stored site data. The tool therefore provides a downloadable project backup for transferring or preserving editable schedule data.

The Bulk Certificate Generator does not currently persist uploaded participant spreadsheets or certificate template files in IndexedDB. Those inputs remain part of the active browser session unless the user downloads generated output.

04

External libraries and delivery services

Some pages load browser libraries and the shared UI package from jsDelivr. Current examples include libraries used for:

  • QR code rendering;
  • PDF processing and certificate PDF-template rendering;
  • GIF encoding;
  • ZIP creation;
  • spreadsheet parsing and writing, including Work Schedule Excel export and participant-list parsing; and
  • certificate PDF generation.

Loading those assets creates normal web requests to the external delivery service. Astakula Tools application code does not intentionally send the contents of tool inputs or locally saved schedule projects to jsDelivr.

GitHub Repository Inspector requests public repository metadata directly from the GitHub REST API at api.github.com. This can expose the requested repository name and standard connection data to GitHub; users do not sign in or provide a token to Astakula Tools. A shared ?repo= link also includes the repository name in the page URL.

The Bulk Certificate Generator also uses the Google Fonts API. When a user selects a supported web font, the browser requests the corresponding stylesheet and font file from Google. That request can expose standard connection data to Google. The participant spreadsheet and certificate template are not intentionally included in the Google Fonts request.

05

Hosting and connection data

Requests for pages and assets can expose standard connection information—such as an IP address, user agent, requested URL, and request time—to hosting, CDN, DNS, font, or network providers involved in delivering the website. Those providers operate under their own terms and privacy practices.

06

Analytics, advertising, and application cookies

No analytics service, advertising tracker, account login, or application-level tracking cookie was identified in the current repository during the October 2026 source audit.

If analytics, advertising, authentication, or additional tracking is introduced later, this statement should be updated before the new behavior is relied upon.

07

Downloads and generated output

Generated files are created for you to download. This includes outputs such as spreadsheets, images, PDFs, Work Schedule Excel or JSON project-backup files, and Certificate Generator PNG ZIP or PDF batches. You are responsible for where downloaded files are stored, shared, or uploaded after they leave the browser workflow.

This policy may be revised when the tools, data flows, browser-storage behavior, hosting setup, or external services change. The effective date shown on this page identifies the version currently represented here.
