What is a work schedule generator?

A work schedule generator assigns employees to configured shifts across a selected month while respecting unavailable dates and basic staffing rules. This implementation also lets you manually adjust generated assignments before exporting.

How to use it

  1. Choose the month, add employees, and configure shifts.
  2. Open each employee's Request Off form and select unavailable dates.
  3. Generate the schedule, review warnings, adjust assignments if needed, then export Excel.

Frequently asked questions

Will my schedule still be here next month?

Yes, if you use the same browser profile and its site data has not been cleared. Projects are stored in IndexedDB on this device.

Is my schedule stored on Astakula's server?

No Astakula application backend is used by this tool. Schedule projects are stored in your browser.

Can I move a project to another computer?

Yes. Download a Backup Project JSON file and import it on the other browser or device.

Are requested days off automatically respected?

Yes. The generator treats saved request dates as unavailable. Manual edits can still override assignments, and validation will flag a requested-off date that has been assigned a shift.
