How should I prepare the certificate design?

Keep all static elements in the template: background, border, logos, title, event text, date, signatures, names of signatories, and decorations. Leave blank areas for recipient-specific data such as a name, company, role, award, or certificate number.

Spreadsheet format

The provided Excel template includes common columns, but it is not mandatory. Your own XLSX or CSV headers are detected automatically and become available as fields in the editor. A participant name is the usual minimum, but the generator does not force a specific header name.

Frequently asked questions

Do I need to redesign the certificate here?

No. This tool is intentionally not a full design editor. Prepare the static design elsewhere, upload it, and use Astakula Tools for the changing recipient data.

Where are my files processed?

The certificate template and participant spreadsheet are processed in this browser. They are not intentionally uploaded to an Astakula application backend.

Why does the tool connect to Google Fonts?

When you choose a font, the browser loads its stylesheet and font file from Google Fonts. The generator waits for the selected font to load before rendering the certificate.

Can I use my existing Excel file?

Yes. Upload an XLSX or CSV file with headers in the first row. Each detected column can be added directly to the certificate.
