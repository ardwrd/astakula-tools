AA normal text

Normal text should reach at least 4.5:1 contrast against its background.

02

Large & non-text

Large text uses a 3:1 AA threshold. UI components and meaningful graphics also commonly target 3:1 against adjacent colors.

03

AAA is stricter

Enhanced contrast for normal text uses 7:1, while large text AAA uses 4.5:1.
