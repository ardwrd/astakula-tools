GitHub Repository Inspector.

Periksa metadata repository GitHub publik tanpa login, token, atau memasang aplikasi.

01 / SEARCH

Cari repository

Contoh: ardwrd/astakula-tools atau https://github.com/ardwrd/astakula-tools

Dijalankan di browser. Pencarian mengirim nama repository dan permintaan jaringan langsung ke api.github.com. GitHub menerapkan batas permintaan untuk akses tanpa autentikasi.

Referensi API resmi GitHub ↗

02 / RESULT

Ringkasan repository

Masukkan repository, lalu pilih Inspect repository.

Buka GitHub ↗ Issues ↗ Pull Requests ↗

Apa yang ditampilkan?

Informasi publik yang dikembalikan GitHub REST API: deskripsi, jumlah stars dan forks, issues terbuka, bahasa utama, lisensi, branch default, serta waktu push terakhir. Angka mengikuti respons GitHub saat pencarian, bukan penghitungan real-time oleh Astakula.

Repository privat tidak bisa diperiksa. Alat ini tidak meminta token, tidak membaca file pribadi, dan tidak menyimpan hasil pencarian ke server Astakula. Lihat Privacy Policy.
